#MSC-SOFTWARE-DEVELOPMENT

This repository contains selected coursework and practice exercises completed as part of an MSc in Software Development.

## Topics covered
- Object-Oriented Programming (Java)
- Databases and data modelling
- Software engineering principles
- HTML & web development
- Introductory tooling and development workflows

This repository is intended to demonstrate foundational programming skills, ongoing learning, and to provide a reference point for tracking technical progress.
